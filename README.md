# Ctrl Alt Lift — UX Design Project

A gamified fitness app UX case study built for CSC7075 (User Experience Design). The project follows a two-round design process — Initial Design and Refined Design — testing a short-session, gamified fitness app concept with a real user group.

## Project summary

The app encourages short, frequent exercise sessions through gamification (progress tracking, streaks, badges) while addressing the real barrier to consistency: not fitness knowledge, but difficulty starting and resuming after a missed day.

Two rounds of user testing (n=7–8) shaped the design:
- **Round 1** tested underlying user goals and attitudes via questionnaire, surfacing findings like the "guilt & catch-up" theme behind missed sessions
- **Round 2** tested working prototypes — including an A/B comparison of two different approaches to handling a missed day — refining the design based on comprehension and preference data

## Methodology notes

- Likert data (n=7–8) analyzed using median/IQR rather than mean/95% CI, given small sample size and ordinal data type
- Comprehension coded (Correct/Partial/Incorrect) against criteria agreed before analysis, to avoid post-hoc bias
- Design A vs. Design B tested within-subjects, with both A/B testing and open-ended follow-up to separate preference from comprehension
